# AI-Hub starter

A React + Vite prototype for an all-in-one AI tools directory.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open a terminal in the folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local address Vite prints (usually http://localhost:5173).

The UI currently includes search, category filters, 80 tool cards, dark/light theme, and a prototype tool workspace. The generation panel is a frontend placeholder; backend/API integration is the next phase.
